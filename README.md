# THE FINALS Comic ITA

Repository canonico per il fumetto fan-made italiano ambientato nell'universo di THE FINALS.

## Obiettivo
Mantenere coerenti trama, continuity, design dei contestant, location e tavole illustrate.

## Struttura
- `CANON.md` — regole canoniche globali
- `CONTINUITY/` — stato attuale, timeline, roster e relazioni
- `CHARACTERS/` — schede personaggio e cartelle reference
- `LOCATIONS/` — schede location e reference
- `STORY/` — sceneggiatura pagina per pagina
- `PAGES/` — prompt e artwork finali
- `TEMPLATES/` — modelli per nuove schede

Le immagini canoniche vanno caricate manualmente nelle cartelle `references/` dei personaggi o delle location.
